# Holy Brook School Website

Official website for **Holy Brook School** (*We Care to Care*), located in Tinsukia, Assam. Built with modern, responsive web technologies including HTML5, Bootstrap 5, FontAwesome, and AOS (Animate On Scroll).

---

## 🏫 About Holy Brook School

Established in 2005, Holy Brook School is committed to providing quality education with a focus on moral values, academic excellence, and overall student development.

---

## ✨ Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices using Bootstrap 5 grid layout.
- **Interactive UI**: Micro-animations powered by AOS (Animate On Scroll) library and custom CSS transitions.
- **School Profile & Faculty**: Detailed information on leadership, teaching faculty, and institutional background.
- **Academics & Admissions**: Academic curriculum, admission process details, online admission application form, and TC application form.
- **Downloads & Resources**: Instant access to official school documents including the School Almanac, Academic Calendar, Celebrations Schedule, and Holiday List.
- **Mandatory Disclosures**: CBSE compliance documents and public disclosure records.
- **Gallery & News**: Photo gallery showcase and news/event updates.

## 🚀 Getting Started

### Prerequisites

No complex server setup is required. All pages are standard static HTML/CSS/JS files and can be hosted on any static web server (GitHub Pages, Vercel, Netlify, Apache, Nginx) or opened directly in a browser.

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-username>/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Open in browser:**
   Open `index.html` in your web browser, or use a local static server extension such as Live Server in VS Code.
